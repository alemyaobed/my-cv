# CV vault

Private repository holding curriculum vitae files and career documents.
Never deployed. The public portfolio lives in the alemyaobed repository.

## Source of truth

The original work documents live at the repository root, exactly as the
owner keeps them. These are the single source of truth:

- weekly report from amazethu
- infra billing
- infra migration chat
- low-cost infra project plan
- step by step migration plan
- render infra

Derived material (generated summaries, the terms map, polished CVs) sits
under documents/ and cv/. If a derived document disagrees with a root
original, the root original wins.

## Structure

- `cv/work/`, `cv/research/`, `cv/resume/` - polished CV set
- `documents/work/PROJECTS-AND-TERMS.md` - names and public-safe wording
- `documents/school/` - applications, recommendations, certificates
- `documents/archive/` - original zips and superseded CV versions

Role timeline derived from the weekly reports: intern Dec 2024 - Apr 2025,
junior Apr 2025 - Jan 2026, cloud & infrastructure Jan 2026 - present.
