# CV vault

Private repository holding curriculum vitae files and career documents.
Never deployed. The public portfolio lives in the alemyaobed repository.

## Structure

- `cv/work/` - polished work CV (current)
- `cv/research/` - polished research CV for graduate applications
- `cv/resume/` - one-page resume
- `documents/work/weekly-reports/` - weekly report chat export (Amazethu)
- `documents/work/infrastructure/` - AWS billing map and migration analysis
- `documents/school/applications/` - statements of purpose, essays, school details
- `documents/school/recommendations/` - recommendation letters
- `documents/school/certificates/` - certificates
- `documents/archive/` - original zips and superseded CV versions

Role timeline derived from the weekly reports: intern Dec 2024 - Apr 2025,
junior Apr 2025 - Jan 2026, cloud & infrastructure Jan 2026 - present.
